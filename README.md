# 🎮 Tic-Tac-Toe Web Application

A fun and interactive **Tic-Tac-Toe Web Application** built using **HTML, CSS, and JavaScript**. This project provides a simple two-player gaming experience with a clean and responsive interface.

## ✨ Features

* 🎮 Two-player gameplay
* ❌ Player X and ⭕ Player O
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 🔄 Restart/New Game functionality
* ⚡ Instant game results
* 📱 Responsive design
* 🎨 Simple and attractive user interface

## 🛠️ Technologies Used

* **HTML5** – Creates the game structure
* **CSS3** – Handles styling, layout, and responsiveness
* **JavaScript** – Controls game logic and user interactions

## 🎯 How to Play

1. Player X starts the game.
2. Players take turns selecting an empty cell.
3. The first player to get **three symbols in a row, column, or diagonal** wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Click the **New Game/Restart** button to play again.

## 🧠 Game Logic

JavaScript is used to:

* Track the current player
* Detect winning combinations
* Prevent moves on occupied cells
* Identify a draw
* Display the game result
* Reset the board for a new game
